## 👋 关于我

- 🤖 **Android 系统层**：CPU 调度与调频（schedutil / WALT / cpufreq）、eBPF、线程负载分类、PMU 性能遥测、SurfaceFlinger
- 🦀 **系统编程**：用 Rust / C++ 写运行在设备上的 native 守护进程，NDK 交叉编译
- 🌐 **Web**：Go 后端 + React 前端，Docker 部署
- ⚙️ **自动化**：GitHub Actions 定时构建与发布
